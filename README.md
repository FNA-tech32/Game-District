## 🛠️ Getting Started & Local Setup

### Prerequisites
- [Node.js](https://nodejs.org/) (`v18.0.0` or higher recommended)
- `npm` (comes bundled with Node) or `pnpm` / `yarn`
- [Git](https://git-scm.com/)

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/Game-District.git
cd Game-District
```

### 2. Install Dependencies
```bash
npm install
```
> *Note: The included `.npmrc` file automatically enables `legacy-peer-deps=true` to seamlessly resolve dependency trees between React 18 and older utility packages.*

### 3. Run the Local Development Server
```bash
npm run dev
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser to inspect the application with hot-module reloading.

## 🔍 SEO & Open Graph Configuration

Each page is configured with search engine metadata and social preview cards defined in [`Layout.js`](file:///c:/Users/QBS%20Accounting/Documents/websites/Game-District/src/layouts/Layout.js):

- **Dynamic Page Titles**: Standard format (`<Page Title> | Game District`).
- **Meta Descriptions**: Targeted descriptions highlighting enterprise capabilities and AI services.
- **Canonical URLs**: Canonical links pointing to `https://gamedistrict.com/<route>`.
- **Open Graph & Twitter Cards**: `summary_large_image` cards for Twitter, Facebook, and LinkedIn previews.
- **Robots Directives**: `index, follow` on all public marketing routes.
